# PCB

Printed circuit boards designed in KiCad. Each board has its own folder with its own README.

- **[ORX_Lite_Receiver](ORX_Lite_Receiver)**: a one-channel optical receiver on a 4-layer, 50 × 40 mm
  board. An S5971 photodiode, an OPA365 transimpedance amplifier and a Sallen-Key low-pass filter feed an
  ADS7042 12-bit, 1 MSPS ADC that sends its samples over SPI to a host board. Revision A is designed and
  its fabrication files are ready; it has not been ordered, built or tested yet.
